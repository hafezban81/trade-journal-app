Data & backup

Everything is saved on this device only. Make a backup now and then — if you delete the app, its data goes with it.

Backup

On iPhone the backup opens the share sheet — choose Save to Files.

Import from Google Sheet

In Google Sheets open the Trade Journal tab, then File → Download → Comma-separated values (.csv). Pick that file here. Trades with the same # are updated; nothing is sent back to the sheet.
